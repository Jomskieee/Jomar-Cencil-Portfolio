Featured · Capstone project

Barangay Health Monitoring System with Heatmap

System name: IneSight, Health Monitoring and Decision Support

A web-based system that keeps barangay health records in one place: maternal health, infant records, vaccination and reported illnesses. A heatmap shows health data by purok, so patterns are easy to see.

My role
Web developer and Systems analyst, as part of the project team: system planning, interface design, database structure, testing and documentation
Stack
  • PHP
  • MySQL
  • PDO
  • mPDF
